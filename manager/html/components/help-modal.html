How .stignore Management Works

stignore-manager coordinates ignore rules and file replication across Syncthing nodes without requiring direct access to each machine.

  • Ignore Item: Appends the relative item path to the agent's .stignore file, excluding it from Syncthing cluster synchronization.
  • Unignore Item: Safely removes the rule from .stignore, resuming sync for that path.
  • Copy Count & Threshold: Tracks how many agents hold a copy of each file against the configured minimum_copies threshold. Items with insufficient copies are flagged with ⚠️.
  • Bulk Actions: Use the multi-agent selection checkboxes in the item details inspector to apply ignore, unignore, or deletion operations simultaneously.
Role-Based Access Control (RBAC)

When header authentication is enabled, operations are role-restricted:
• Admin: Full read and write access (Ignore, Unignore, Delete, Toggle Agents).
• Reader: Read-only browsing and status inspection.

Pattern Syntax Rules
Pattern Description Example
filename Matches file/dir anywhere in tree .DS_Store, *.nfo
/dir/ Matches directory relative to category root /Movie A (1989)/
* / ? Wildcard (multi / single char) *sample*.mkv, Season ?/
** Recursive directory match **/extras/
!pattern Inversion / exception rule (include) !TV Show A (2003)/Season 01/
(?i) Case-insensitive matching prefix (?i)*sample*.mkv
(?d) Allow parent directory deletion (?d).DS_Store
#include Include external rules file #include .stglobalignore
Movies & TV Shows
# Ignore a whole movie
Movie A (1989)/

# Ignore a specific TV season
TV Show A (2003)/Season 1/*
TV Show A (2003)/Specials/

# Ignore movie extras & samples
Movie A (1989)/extras/
(?i)*sample*.mkv

# Sync ONLY Season 1 (ignore the rest)
!TV Show A (2003)/Season 01/
TV Show A (2003)/*

# Ignore metadata & sidecars
*.nfo
*.sfv
OS & Metadata Junk
# macOS metadata
(?d).DS_Store
(?d)._*

# Windows thumbnails & desktop
(?d)Thumbs.db
(?d)desktop.ini

# Synology & NAS indexing
(?d)@eaDir/
(?d).Trash-*/

# Partial / temp downloads
*.tmp
